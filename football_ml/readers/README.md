# Readers

This directory contains scripts for reading and processing data from various football data sources.

## Data Sources

Currently supported data sources:
- **SkillCorner** - Tracking and event data
- **StatsBomb** - Event data and statistics
- **Transfermarkt** - Player transfer and market value data
- **Metrica-Sports** - Sample tracking and event data for research purposes

## Overview

The scripts in this catalog are designed to read and parse sample data from the above sources. Each data source may have its own specific reader implementation to handle different data formats and structures.

## Future Development

This list of data sources will expand over time as additional integrations are added.

## Usage

Each reader script is tailored to its respective data source format and provides standardized methods for data extraction and processing.
